# TaskTracker

Production-ready full-stack task management platform built with ASP.NET Core Web API, React, and PostgreSQL.

## Live Application

🚀 https://canncodehub.com

> The application is actively deployed and running on a Linux VPS environment with Nginx reverse proxy configuration.

---

## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- FluentValidation

### Frontend
- React
- TypeScript
- Vite
- Axios

### DevOps & Deployment
- Ubuntu VPS
- Nginx Reverse Proxy
- Systemd Service
- Domain Configuration

---

## Features

- JWT Authentication

## Why This Project?

This project was developed not only to build CRUD operations, but also to gain real-world software engineering experience including:

- Production deployment
- Backend architecture
- Authentication systems
- Secure API development
- Frontend/backend integration
- Linux server management

---

## Architecture

The backend follows a layered architecture:

- API Layer
- Business Layer
- Data Access Layer
- Core Layer
- Entity Layer

This structure improves scalability, maintainability, and separation of concerns.
